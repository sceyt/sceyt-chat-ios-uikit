# Security policy

Report suspected vulnerabilities in the Sceyt Chat iOS UIKit privately by emailing [support@sceyt.com](mailto:support@sceyt.com). Include the UIKit version or commit, the iOS version and device, the potential impact, and enough detail for the maintainers to investigate.

Remove credentials, access tokens, and personal data such as messages and user details from any logs or attachments. Keep the report private while the maintainers investigate and coordinate disclosure with you.
